RupeeFlow — Setup Checker

1 App files idle

Are all five files reachable next to this page? (Icons/manifest are only needed for home-screen install.)

2 Origin & protocol idle

Google sign-in and home-screen install require HTTPS, or http://localhost. This also prints the exact origin string to paste into Google Cloud.

3 Device storage idle

RupeeFlow saves on-device data in localStorage. Sandboxed frames and some private modes block it — the app then runs in memory-only mode.

4 Offline & installability idle

Uses the service worker (sw.js) so the app opens with no network and can be added to the home screen.

5 Google sign-in reachability idle

Loads accounts.google.com/gsi/client. Must succeed for the normal Connect flow.

6 Client ID & sign-in idle

Paste the Client ID from Google Cloud → Clients. It is validated, then used for a real sign-in.

7 Drive + Sheets API idle

With a token: finds or creates the RupeeFlow spreadsheet, writes a test value, reads it back, and lists its tabs.

? If a check fails

  1. Open SETUP.md → §11 Troubleshooting and match the exact error text.
  2. Most failures are one of: origin not registered (no path / no trailing slash), Sheets or Drive API not enabled, your Gmail not added as a Test user, or the page being inside a sandboxed/in-app browser.
  3. Google Cloud changes can take ~5 minutes to take effect — retry after a short wait.
